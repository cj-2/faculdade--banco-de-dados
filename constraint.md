
# Constraint (Restrições)

São regras básicas estabelecidas para o preenchimento de uma ou mais colunas de uma 
tabela. Ou seja, restrigem os dados que podem ser salvos nas colunas.

Principais:
- Not null
- Unique Key
- Primary Key
- Foreign Key References
- Check Constraints
